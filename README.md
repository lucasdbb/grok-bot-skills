# Skills dos Grok Bots do Lucas

Cópia das skills criadas pelos bots do Lucas Braga no Grok Bot (pasta `/home/box/agent-data/workflows`).
Cada pasta em `skills/` é uma skill com o seu `SKILL.md`.

- A fonte de verdade continua sendo o Grok Bot; este repositório é a cópia versionada.
- Skills gerenciadas pela Cursor e skills de plugins não entram aqui.
- Nunca coloque senha, token ou chave em uma skill.
