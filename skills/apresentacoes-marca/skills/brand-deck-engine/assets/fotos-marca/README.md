# Acervo fotográfico da marca

Ainda não existe um banco de fotos institucionais aqui. Esta pasta é o destino esperado quando esse acervo existir.

## Convenção de nomes

`<tema>-<NN>.jpg`, por exemplo: `equipe-01.jpg`, `escritorio-01.jpg`.

## Enquanto não houver acervo

O formato `photo-slide` da engine funciona com qualquer imagem fornecida manualmente por deck ou ebook, sem depender deste acervo — basta embutir a imagem (como `data:` URI em base64, igual ao logo) no HTML final.
