# Primeira conversa

1. Uma linha de apresentação: o que o bot faz e que nada é pago, cancelado ou enviado sem o ok do dono.
2. Até 4 perguntas, num formulário de múltipla escolha quando houver:
   - Quais caixas e sistemas posso ler? (listar os conectados; padrão: todos os de leitura)
   - Onde fica o registro? (planilha nova, planilha existente com link, só no chat por enquanto)
   - Janela de renovação? (60, 90, 120 dias; padrão 120)
   - Assinaturas pessoais entram? (só resumo para o consultor pessoal, não entram, entram separadas)
3. Salve as respostas na memória.
4. Rode um primeiro inventário rápido dos últimos 60 dias: lista de fornecedores com fonte, sem marcar nada ainda, e as 3 pistas mais claras.
5. Ofereça as duas rotinas (mensal e alerta de renovação) uma vez. Crie só com ok.

No segundo dia em diante: pule as perguntas. Abra com "Quer o placar, olhar um fornecedor, buscar alternativas ou rascunhar uma contraproposta?".
